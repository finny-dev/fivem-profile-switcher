## Installation / Setup
- Download the .bat file
- Replace .bat with .txt (So you can edit it)
- Replace the paths on line 3 & 4 to your paths

- Create a "profiles" folder in your designated path
- Make sure this folders location matches whats in the .bat file

Everything else should be automated
